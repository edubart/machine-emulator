# Emulator assumptions made by the Lua PRT validator node

This catalog lists what the experimental Lua PRT node in `doc/recipes/` (branch `feature/prt`) assumes about the emulator's behavior. Each assumption comes from an `assert` on an emulator result, a comment stating a guarantee, the order in which the node composes calls, its error handling (nearly every emulator error is fatal, and the only retry is a crash followed by a replay under `prt-supervise.sh`), its crash-recovery path, or what it implicitly expects about time, resources and determinism. `PRT-APIS.md` lists the APIs. This file lists the assumptions behind them. File references are `file:line` on the current branch. Recipes are in `doc/recipes/` and emulator code is in `src/`. Known issues from `BUGS.md` that touch an assumption are cited as `Bnn`. The assumptions fall into eight groups, one table per group, so each group can go to a separate bug hunter.
